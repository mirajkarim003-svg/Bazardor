# 🛒 বাজার দর (BazarDor)

প্রয়োজনীয় পণ্যের দাম এক নজরে।

BazarDor is a Bengali market price tracker that helps users check everyday product prices and compare price changes across different markets.

## ✨ Features

- Scrolling ticker showing product prices and daily changes.
- Daily price increases and decreases.
- Browse products by category and sort by price.
- Product details with market-wise prices.
- Sign in and sign up with Better Auth.
- Profile management and protected pages.
- Responsive design for mobile, tablet, and desktop.
- Loading skeletons and a custom 404 page.

## 🛠️ Technologies Used

- Next.js
- TypeScript
- Tailwind CSS
- Better Auth
- MongoDB
- react-hot-toast
